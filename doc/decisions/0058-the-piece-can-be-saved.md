# 0058 The piece can be saved as JSON or an s-expression, with `notasi render --save-piece`

Status: accepted (2026-11-26)

Context: What the reader made of a piece (every part's events with their exact times, the generated gong and kempli parts, the pattern spans, the scores' settings) is visible only through a drawing or from a Guile REPL. ADR 0015 says anyone who wants analysis builds it outside notasi on the piece records, but that needs notasi's modules. The figure JSON (ADR 0006) is layout's output for one score, not the piece. The backlog asked for `notasi describe FILE` and for a check that finds mistakes without drawing.

Decision: `notasi render PIECE.nts --save-piece FILE` saves the piece record (02) after reading: JSON for a `.json` file, an s-expression for `.scm`, JSON on standard output for `-` (then nothing else is printed there); any other extension is a usage error. It is an option on `render`, not a subcommand, because saving goes with drawing; with `--list` it saves and draws nothing, needing no Typst, which also serves the backlog's `describe` and its faster check. The saved piece is always the whole piece, whatever is drawn, field for field, with each definition's source location; exact times are JSON numbers when whole and strings in lowest terms (`"5/4"`) otherwise, and exact rationals in the s-expression, which is tagged lists that notasi writes and never reads. It has a `version` field and golden files from the start, but is not yet a promised contract: it may change between versions, without an ADR, until it settles. ADR 0018's one command stands; its consequence that a feature means a subcommand doesn't hold for this option.

Consequences: Writers and developers can see what notasi understood, and other tools can use the music from any language that reads JSON, without notasi's modules. `render`'s options, a contract for editors (ADR 0048), grow; editors don't use this one. A new writer for the piece sits beside `(notasi json)`, which writes the figure, with its own tests and golden files. Every change to the piece records now shows in the saved piece's golden files.
