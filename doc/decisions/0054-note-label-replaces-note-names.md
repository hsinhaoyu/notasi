# 0054 `:note-label` chooses what a note shows, and the pitch column is set apart

Status: accepted (2026-11-26)

Context: A note can show its name or nothing (`:note-names yes/no`). Collapsed rows (ADR 0055) rely on what is written in a note, since a row no longer stands for a pitch, and a writer may want a note's key number in it, which today can only be a column beside the row labels (`:key-numbers`). The octave number is set once (`:octave-numbers`) for the row labels and the note names together, and the documents called the same things a degree, a degree name, a note name and a display form.

Decision: `:note-label none/pitch-name/pitch-display-name/key-number` (default `none`) chooses what is written in each note, on a score or a group: nothing, the pitch name (`dong2`), the pitch display name (`o2`) or the key number (`2`). Strokes show their name with `pitch-name`, and their display name with `pitch-display-name` and `key-number`. `:row-labels` is widened to choose the pitch column's form, `none/pitch-name/pitch-display-name` (default `pitch-display-name`). The octave number is set apart for each, by `:row-label-octave yes/no` and `:note-label-octave yes/no` (default `yes`). `:note-names` and `:octave-numbers` are removed, and `:row-labels yes/no` become unknown values, with no migration. Only `:fill none` needs a label; `parts` and compact rows may be colour only. The damped form is shown only by `pitch-display-name` (and strokes), as today. The glossary's terms (ADR 0051) are used: pitch, pitch name, pitch display name, key number.

Consequences: Existing scores on `notes` rows draw as now unless they wrote `:note-names yes`, which every example that did must rewrite as `:note-label pitch-display-name`. The reader, layout and their tests, the examples and golden files, the manual and the Emacs mode's completion change. The figure JSON needn't change: an event's `text` carries a key number as a string. Damped forms for `pitch-name` and `key-number` are left until a piece needs them.
