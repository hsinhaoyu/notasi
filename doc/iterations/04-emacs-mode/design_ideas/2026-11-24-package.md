# Design idea: the package

Status: agreed in discussion (2026-11-24); see "Settled". Not the
design until promoted.

## The idea

- **Where it lives:** `editors/emacs/notasi-mode.el`, in the notasi
  repo. One file if it stays small; `notasi-mode-*.el` beside it if
  not.
- **A proper Emacs package:** the standard headers, with
  `Package-Requires: ((emacs "29.1"))` and a `Version:` that is
  notasi's version; `lexical-binding`; autoload cookies on the mode
  and on the `.nts` entry in `auto-mode-alist`, so installing is
  enough and nothing needs `require`; every setting in a `notasi`
  customisation group.
- **Shipped to users:** `editors/` is released to `main` with the rest
  of notasi (the release skill must not treat it as dev-only), and
  released with the same version tag.
- **Installing**, easiest first:
  1. From GitHub, with `package-vc` (built into Emacs 29) or
     `use-package :vc` (Emacs 30):

         (use-package notasi-mode
           :vc (:url "https://github.com/hsinhaoyu/notasi"
                :lisp-dir "editors/emacs"))

  2. From a clone of the repo, by adding `editors/emacs` to
     `load-path`.
  3. Later, MELPA, with a recipe that takes the `.el` files from
     `editors/emacs`.
- **Quality:** byte-compiles with no warnings, passes `checkdoc` and
  `package-lint` (MELPA asks for both), checked by
  `make check-emacs`.

## Open

- The package's name: `notasi-mode` or `notasi`? `notasi` is shorter
  in `use-package`, but the command has that name too. Suggested:
  `notasi-mode`.
- Emacs 29 as the oldest? `use-package :vc` needs 30. Suggested: 29,
  with `package-vc-install` in the README for 29 users.
- Submit to MELPA in this iteration, or after? Suggested: after, once
  the mode has been used for a while.

## Settled (2026-11-24)

- **The name** is `notasi-mode`.
- **Emacs 29.1** is the oldest supported; the README gives
  `package-vc-install` for Emacs 29 and `use-package :vc` for 30.
- **MELPA** after this iteration, once the mode has been used for a
  while.
- **`editors/` ships to `main`** with `/release` (the release skill
  does not treat it as dev-only). Until notasi is released to `main`,
  the README installs the package from `dev`.
