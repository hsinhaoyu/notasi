# Introduction

notasi turns gamelan music, typed as short lines of text, into clear,
colourful score figures.

You write each part the way you would say it, note by note, with how
long each one lasts. notasi lines the parts up on a grid, gives every note its own row,
and draws the result, so you can see at a glance how the polos and
sangsih lock together, or where the gong falls in the cycle (see
[Drawing a score](drawing.md)).

If you write in Emacs, notasi can draw your score beside the text as you
write: see [Writing in Emacs](emacs-installing.md).

notasi is young and still being built. This manual grows with it: each
page describes something you can already do. If a page you're looking
for isn't here yet, that part isn't ready.
